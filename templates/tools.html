Import runner database (CSV or IOF XML)

The runner database the entry page and the editor autofill from, kept for every future event. A CSV with name (or first + last), club, card and optional class, or MeOS's runner database export / an Eventor member list (IOF XML CompetitorList). Keyed by SI card: rows without a card are skipped, re-importing a card updates it.

Import start list (CSV or IOF XML)

CSV columns: name, club, class, card, start (start as HH:MM:SS). Classes must already exist.

Import results (IOF XML ResultList)

Bring a past event across from MeOS (or anything that exports IOF XML 3.0 results): runners, times and punches are recreated and re-checked here. Import the courses first for exact courses; otherwise each missing class gets a course built from its winner's splits.
